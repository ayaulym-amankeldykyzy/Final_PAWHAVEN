PAWHAVEN — Final Project

HOW TO RUN
1. Extract the complete project folder.
2. Open the folder in Visual Studio Code.
3. Start index.html with Live Server (recommended), or use another local web server.

PROJECT STRUCTURE
- *.html       Separate pages and page content.
- css/         All project stylesheets.
- js/          All project JavaScript functionality.
- images/      Local photos and graphics used by the website.
- vendor/      Third-party libraries used by the project (Bootstrap CSS, Bootstrap JavaScript bundle, and jQuery).

WHY THE vendor FOLDER EXISTS
The vendor folder contains libraries created by their respective authors; it is not extra project code generated by us.
Bootstrap provides the existing layout/components and its JavaScript bundle. jQuery is used by a few existing interface effects (toast messages and animated counters). These files are stored locally so the website can load them without downloading them from a CDN each time. Do not delete vendor/ unless the Bootstrap and jQuery dependencies are first removed or replaced in the project.

CODE ORGANIZATION
- Keep page structure in HTML.
- Keep visual design in css/style.css and css/final.css.
- Keep application behavior in js/*.js.
- The <script src="..."> elements in HTML are only external file references. They load JavaScript files; they do not contain the JavaScript implementation.
- Hosting-platform injected inline challenge scripts have been removed from the HTML because they are not part of the project.

IMPORTANT
This is a front-end student demo. Authentication and cart data use the browser's localStorage; do not use real passwords or payment information.
